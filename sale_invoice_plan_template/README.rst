Reusable payer splits for the invoice plan by payer
(``sale_invoice_plan_partner``).

A template lists the payers and the share of each one. Set it on the
customer and new sales orders of that customer start with the *Payers*
plan already filled in. A template line without partner stands for the
invoice address of the order, so one template can serve several
customers (e.g. "customer 50%, leasing company 50%").

   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.

Usage
=====

- In *Sales > Configuration > Sales Orders > Invoice Plan Templates*,
  create a template with the payers and their percentages (100% in
  total).
- Set the template on the customer, in the *Sales & Purchase* tab.
- New quotations of the customer load the payers of the template. On a
  quotation, choose another template or click *Load payers* to load it
  again.
